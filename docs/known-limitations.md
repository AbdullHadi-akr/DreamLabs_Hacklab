# Known limitations

- Real inference spending cannot be bounded in dollars from this dashboard. A request limit bounds call count, and the account remains the source for billing.
- State-based automatic scoring is strongest for supported object placement tasks with observable target, release and stability. Unsupported tasks remain unknown unless independently evaluated.
- The existing standard suite supports Quick Test, Repeated Runs and A/B Comparison. The sprint did not add a scenario-collection editor or saved regression baseline workflow.
- The repository has a JavaScript report regression harness. This sprint did not establish automated coverage across the six browser resolutions, for browser console errors, or for a recording takeover workflow.
- The campaign coordinator can be reused via explicit ownership boundaries. Robustness should keep its own planners, trial semantics and artifact contract until a planned integration.
